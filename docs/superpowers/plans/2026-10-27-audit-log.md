# Аудит-лог («Журнал дій») Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Замінити `ProgressAuditLog` єдиним append-only журналом `AuditLog`, який пишеться явними викликами в сервісах (проба, люди й ролі, гроші й майно, налаштування) і читається лише звʼязковим на сторінці «Журнал дій».

**Architecture:** Глобальний `AuditModule` експортує `AuditService.record()` (помилка запису логується і ковтається). Сервіси викликають його після успішної дії. `GET /kurins/:kurinId/audit-log` (лише `ZVYAZKOVYI`) віддає курсорну сторінку з фільтрами. Фронтенд будує текст події чистою функцією `describeAuditEvent(action, details)`.

**Tech Stack:** NestJS 10 + Prisma 5 (PostgreSQL), Jest + supertest (e2e), Next.js (App Router) + TanStack Query, Playwright (e2e фронтенду).

Spec: `docs/superpowers/specs/2026-10-27-audit-log-design.md`.

## Global Constraints

- Журнал **append-only**: жодних ендпоінтів зміни чи видалення записів.
- `record()` викликається **після** успішної дії; збій запису не ламає дію (try/catch + `Logger.error`).
- Читати журнал може **лише звʼязковий** свого куреня; `kurinId` шляху ≠ `user.kurinId` → 404.
- `details` зберігає читабельні назви «як були на момент події» (імена, назви точок), не лише id.
- Нічний автосинк у Книгу судді пишеться **одним** підсумковим записом з `actorId = null` («Система»), без рядка на кожного юнака.
- Поза скоупом: відкат, експорт, сповіщення, вкладка «Історія» на картці юнака, логування читання/входів, автоочищення.
- Тексти для користувача — українською, без росіянізмів.
- Запуск e2e (з `apps/api`): `NODE_OPTIONS=--max-old-space-size=8192 npx jest --config ./test/jest-e2e.json --runInBand <file>`. Потрібні: піднятий Postgres, міграції накочені на `plast_test` (`set -a; . ./.env; set +a; DATABASE_URL="$DATABASE_URL_TEST" npx prisma migrate deploy`), та `VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY` у середовищі (тимчасові: `node -e "console.log(require('web-push').generateVAPIDKeys())"`).
- Якщо сервіс, у який додається `AuditService`, створюється вручну (`new XService(...)`) у unit-спеках — передати `{ record: jest.fn() } as any` і прогнати ці спеки.

-- Carry the existing proby confirm/unconfirm history over into the new log.
INSERT INTO "AuditLog" ("id", "kurinId", "actorId", "action", "subjectUserId", "entityId", "details", "createdAt")
SELECT
  p."id",
  u."kurinId",
  p."actorId",

  p."junakId",
  p."pointId",

    'pointTitle', pt."description",
    'subjectName', COALESCE(NULLIF(BTRIM(u."nickname"), ''), u."firstName" || ' ' || u."lastName")
  ),
  p."createdAt"
FROM "ProgressAuditLog" p
JOIN "User" u ON u."id" = p."junakId"
LEFT JOIN "ProbyPoint" pt ON pt."id" = p."pointId";

`apps/api/src/audit/audit.service.ts` (на цьому кроці лише `record`; `list` додається в Task 2):

```ts
import { Injectable, Logger } from '@nestjs/common';
import { AuditAction, Prisma } from '@prisma/client';
import { PrismaService } from '../prisma/prisma.service';

export interface AuditEvent {
  kurinId: string;
  actorId: string | null;
  action: AuditAction;
  subjectUserId?: string | null;
  entityId?: string | null;
  details?: Record<string, unknown>;
}

@Injectable()
export class AuditService {
  private readonly logger = new Logger(AuditService.name);

  constructor(private readonly prisma: PrismaService) {}

  /** Never throws: a failed audit write must not break the action that already succeeded. */
  async record(event: AuditEvent): Promise<void> {
    try {
      await this.prisma.auditLog.create({
        data: {
          kurinId: event.kurinId,
          actorId: event.actorId,
          action: event.action,
          subjectUserId: event.subjectUserId,
          entityId: event.entityId,
          details: event.details as Prisma.InputJsonValue | undefined,
        },
      });
    } catch (error) {
      this.logger.error(`Failed to record audit event ${event.action}: ${(error as Error).message}`);
    }
  }
}
```

  async list(kurinId: string, dto: ListAuditLogDto) {
    const limit = dto.limit ?? 50;
    const where: Prisma.AuditLogWhereInput = { kurinId };
    if (dto.group) where.action = { in: AUDIT_GROUPS[dto.group] };
    if (dto.actorId) where.actorId = dto.actorId;
    if (dto.subjectUserId) where.subjectUserId = dto.subjectUserId;
    if (dto.from || dto.to) {
      where.createdAt = {
        ...(dto.from ? { gte: new Date(dto.from) } : {}),
        // `to` is a date: include the whole day.
        ...(dto.to ? { lt: new Date(new Date(dto.to).getTime() + 24 * 60 * 60 * 1000) } : {}),
      };
    }
    if (dto.cursor) {
      const [createdAtIso, id] = dto.cursor.split('|');
      const cursorDate = new Date(createdAtIso);
      if (!id || Number.isNaN(cursorDate.getTime())) {
        throw new BadRequestException('Недійсний курсор');
      }
      where.AND = [
        {
          OR: [{ createdAt: { lt: cursorDate } }, { createdAt: cursorDate, id: { lt: id } }],
        },
      ];
    }

    const rows = await this.prisma.auditLog.findMany({
      where,
      orderBy: [{ createdAt: 'desc' }, { id: 'desc' }],
      take: limit + 1,
      include: { actor: { select: { id: true, firstName: true, lastName: true, nickname: true } } },
    });
    const page = rows.slice(0, limit);
    const last = page[page.length - 1];
    return {
      items: page.map((row) => ({
        id: row.id,
        action: row.action,
        createdAt: row.createdAt.toISOString(),
        actor: row.actor ? { id: row.actor.id, name: personLabel(row.actor) } : null,
        subjectUserId: row.subjectUserId,
        entityId: row.entityId,
        details: row.details as Record<string, unknown> | null,
      })),
      nextCursor: rows.length > limit && last ? `${last.createdAt.toISOString()}|${last.id}` : null,
    };
  }

'use client';

import { useInfiniteQuery } from '@tanstack/react-query';
import { apiFetch } from '@/lib/api-client';
import type { AuditGroup, AuditLogPage } from '@/lib/audit';

export interface AuditLogFilters {
  group?: AuditGroup;
  actorId?: string;
  from?: string;
  to?: string;
}

export function useAuditLog(kurinId: string | undefined, filters: AuditLogFilters) {
  return useInfiniteQuery({
    queryKey: ['audit-log', kurinId, filters],
    enabled: !!kurinId,
    initialPageParam: undefined as string | undefined,
    queryFn: ({ pageParam }) => {
      const params = new URLSearchParams();
      Object.entries(filters).forEach(([key, value]) => value && params.set(key, value));
      if (pageParam) params.set('cursor', pageParam);
      const qs = params.toString();
      return apiFetch<AuditLogPage>(`/kurins/${kurinId}/audit-log${qs ? `?${qs}` : ''}`);
    },
    getNextPageParam: (last) => last.nextCursor ?? undefined,
  });
}
